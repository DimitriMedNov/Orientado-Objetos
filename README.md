# Programación Orientada a Objetos

Trabajos de la materia de programación orientada a objetos de la Universidad Anáhuac Mayab, en **Java, C# y Python**.

## Qué hay

### Primer parcial
Clases propias construidas desde cero: `Point3D` implementada en los tres lenguajes para comparar cómo cambia, además de `Agenda`, `Book`, `Date`, `Complex` y `Vector`.

### Segundo parcial
`Persona` en C# y Java, números complejos y **cuaterniones**, manejo de excepciones, jerarquía de figuras geométricas, un arreglo propio (`MyArray`) e interfaces gráficas.

### Othello
El juego completo, con tablero, reglas de volteo de fichas, turnos e interfaz en Swing. Incluye sus propias excepciones (`LugarInvalido`, `EntradaIncorrecta`) y una clase de pruebas.

## Stack

Java · C# · Python · Swing

> Las salidas de compilación se sacaron del repositorio: pesaban más que todo el código junto.
